# 스핔 (Spk)

모나티엄에서 만든 세계수 교단 설교용 언어다.
울음소리(흐에엥) 길이로 수를 세며, 트릭컬이 서비스 종료하기 전까지 스피키... 아니 네르 제사장이 설교를 이끈다.

## 실행 방법

Node.js처럼 전역 설치 또는 npx로 실행할 수 있다.

```bash
npm i -g spklang
spklang [파일.spk]
```

또는 npx:

```bash
npx spklang [파일.spk]
```

표준 입력은 프로그램의 입력으로 전달된다. (`echo "hello" | spk prog.spk`)

### npm에 배포할 때

1. **spk-core** 먼저 배포: `cd packages/spk-core && pnpm publish`
2. **spk** 배포: `cd packages/spk && pnpm publish`

최초 한 번 `npm login`으로 로그인해 두면 된다. 패키지 이름 `spk`가 이미 사용 중이면 `package.json`의 `name`을 `@내npm유저명/spk`처럼 스코프로 바꾸면 된다. (설치 시 `npm i -g @내npm유저명/spk`)

## 기본 설정

| 항목                  | 내용                                                     |
| --------------------- | -------------------------------------------------------- |
| **파일 확장자** | `.spk`                                                 |
| **설교 개시**   | `세계수 교단의 제사장 네르에요`                        |
| **설교 종료**   | `이단 척결의 시간입니다`                               |
| **런타임 성공** | `오늘의 설교시간이 돌아왔어요오`                       |
| **런타임 에러** | `다들 너무하는 거 같아요오 스피키 큰 잘못한 건 없는데` |

## 문법 구조

### A. 수와 연산

`흐` 뒤에 달리는 `에` 개수만큼이 숫자를 이룬다.

| 숫자 | 표현                             |
| ---- | -------------------------------- |
| 1    | `흐에엥`                       |
| 2    | `흐에에엥`                     |
| 3    | `흐에에에엥`                   |
| n    | `흐` + (n개의 `에`) + `엥` |

**곱하기**는 공백으로 이어 붙인다. (예: `흐에에엥 흐에에에엥` = 2 × 3 = 6)

---

### B. 변수와 대입

**주어 (사도)**

| 표현     | 의미                  |
| -------- | --------------------- |
| `흐`   | 첫 번째 사도 (변수 1) |
| `흐흐` | 두 번째 사도 (변수 2) |

**서술어 (대입)**: `스피키 네르지 마세요`

```
[주어] 스피키 네르지 마세요 [값]
```

→ **[주어]**에게 **[값]**을 부여한다. (스피키에게 네르지 마시고 그 값을 넘긴다.)

**예시**

```
흐 스피키 네르지 마세요 흐에엥
```

→ 첫 번째 사도에게 1을 부여한다.

```
흐흐 스피키 네르지 마세요 흐 흐에에엥
```

→ 두 번째 사도에게 (첫 번째 사도 값 + 2)를 부여한다.

---

### C. 입출력

**입력**

```
[주어] 스핔
```

→ [주어]가 밖에서 말을 듣고 온다. 그 말을 해당 사도에게 기록한다.

**출력**

| 구문                              | 의미            |
| --------------------------------- | --------------- |
| `쪼아요 쪼아요 호박이 쪼아요`   | 숫자로 발언한다 |
| `쪼아요 쪼아요 물걸레질 쪼아요` | 글자로 발언한다 |
| `쪼아요 쪼아요 숨바꼭질 쪼아요` | 줄을 바꾼다     |

---

### D. 흐름 제어

**반복/조건 개시**: `스핔 [조건]`

- 조건이 **0**이면 → 그 구간을 건너뛴다.
- 조건이 **0이 아니면** → 안쪽을 실행한다.

**반복/조건 종료**: `네르지 마세요`

→ 해당 `스핔`로 되돌아간다.

---

## 프로젝트 구조 (모노레포)

pnpm 워크스페이스 기반 모노레포다.

| 패키지                | 설명                                               |
| --------------------- | -------------------------------------------------- |
| `packages/spk-core` | TypeScript 인터프리터 (lexer, parser, interpreter) |
| `packages/spk-web`  | Svelte SPA — 설교문 편집 및 실행                  |

### 사용 방법

```bash
pnpm install
pnpm run build
pnpm run dev
```

- **개발**: `pnpm run dev` → `http://localhost:5173` 에서 웹 에디터 실행
- **GitHub Pages**: `main` 푸시 시 자동 배포 → https://service-end.github.io/spk/
- **빌드**: `pnpm run build` → 루트에서 모든 패키지 빌드
- **spk-core만 사용**: `import { runSource, parse, run } from 'spk-core'`
